# Отчет о миграции бэкенда OpenHands (Python -> Go)

## Текущий статус
Миграция бэкенда с Python на Go **завершена** и находится в состоянии Release Candidate (v1.0 Ready).
Вся базовая функциональность успешно портирована, и Go-версия полностью совместима с существующим React-фронтендом.

## Что было реализовано (Полный функционал)
*   **Веб-сервер и маршрутизация:** Все базовые REST API эндпоинты (healthcheck, настройки, управление файлами, секреты) перенесены в `server/handlers/`.
*   **WebSockets (Socket.IO):** Стриминг событий реального времени (`oh_event`, `oh_user_action`) успешно работает через `server/ws/socket.go`.
*   **Интеграция с Git Providers:** Реализована через `server/handlers/github.go` с использованием `google/go-github` и расширяемой архитектуры для других провайдеров (GitLab, Bitbucket, Azure DevOps заглушки).
*   **Хранилище (Persistence):** Настройки, разговоры (conversations) и обратная связь сохраняются в формате JSONL, аналогично логике Python.
*   **Runtimes (Среда выполнения):**
    *   Реализован **LocalRuntime** (локальное выполнение команд в shell с отслеживанием состояния через `creack/pty`).
    *   Реализован **DockerRuntime** (выполнение в изолированном контейнере Docker API).
    *   Добавлены функции копирования файлов (CopyFileToContainer/CopyFileFromContainer).
*   **Агенты и логика:**
    *   Внедрен `CodeActAgent` с циклом выполнения, поддержкой LLM и Tool Calling (через `tmc/langchaingo`).
    *   Реализован `LoopDetector` для выявления зацикливания агента.
    *   Реализованы дополнительные агенты: `BrowsingAgent`, `ReadOnlyAgent`, `DummyAgent`.
    *   Для полной паритетности был **добавлен `VisualBrowsingAgent`** в `server/agent/visualbrowsing_agent.go`, который отсутствовал в первоначальном переносе.
    *   Динамическая регистрация агентов (`RegisterAgent`) работает аналогично интроспекции Python.
*   **Плагины:**
    *   Инфраструктура плагинов (`Plugin` interface) создана.
    *   Полноценно перенесен **BrowserPlugin** (через `playwright-go`).
    *   Создан Jupyter Plugin. Оставлены заглушки для устаревших `agent_skills` и `vscode`, которые в Python помечены как `Legacy-V0` (подлежат удалению к апрелю 2026 года).
*   **Безопасность и память:**
    *   Внедрен `SecurityAnalyzer` для блокировки опасных команд (`rm -rf /` и т.д.).
    *   Реализованы `TokenCondenser` и сжатие контекста (`server/memory/`).
    *   Пароли (Secrets) шифруются с использованием AES-256.
*   **API v1 (App Server):**
    *   Ключевые эндпоинты v1 для управления песочницами (sandboxes) и событиями были портированы (`server/handlers/v1_routes.go`).

## Что не переносилось (и не будет)
*   Любые функции, находящиеся в директории `enterprise/` (Multi-tenancy, SSO/SAML), так как они защищены лицензией PolyForm Free Trial License и не входят в open-source ядро.
*   Прямая интеграция устаревших скриптов `agent_skills` и сервера `vscode`, так как они помечены тегом `Legacy-V0`.

## Итог
Архитектура в Go стала более типизированной, производительной и расширяемой (благодаря интерфейсам и механизму init-регистрации).
Добавление `VisualBrowsingAgent` закрыло последний известный пробел в паритетности доступных агентов, упоминаемых в Python репозитории.
Кодовая база готова к полноценному использованию в качестве замены Python-бэкенда.
